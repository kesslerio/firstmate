Pi worker model-stream observation is optional. Set FM_STREAM_SILENT_MAX_SECS=300 before launching workers and their watcher to inspect a foreground request that stops producing substantive content for five minutes. It must be present in the environment that launches both the worker and its watcher: a value only the watcher sees, such as one added only to config/watch.env, instruments no worker, so a worker spawned without it records no stream evidence and keeps the general busy bound. The interval includes foreground request preparation; the existing wedge delay and declared-wait deferrals still apply before an inspection notification, and no worker is interrupted or restarted. Background provider/cache warming is excluded, and observation closes at assistant message completion, tool execution start, or settled idle state. Changed nonempty text, thinking, or tool-call content refreshes stream evidence at most once per second and supplies a separate progress anchor for the general busy bound; empty or unchanged snapshots do not. New instrumentation is version-gated to Pi 1.2.0 and takes effect on launch or relaunch; stream observation stays off on every unverified version until verified, with a warning and the general busy bound retained. Observation writes have a five-second subprocess deadline and one-second termination grace; a failed write reports an instrumentation warning while Pi continues. Unset, empty, zero, negative, malformed, and values longer than nine decimal digits disable the option, including its separate normal-model progress anchor. bin/fm-busy-lib.sh owns stream evidence and ordering; the real-Pi verification guard refreshes the vendor evidence.
